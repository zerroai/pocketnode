# Pocketnode brand

Direction: black and silver, the existing ring and dot logo, icons on black tiles with silver glyphs (style A). Everything lives in this folder on your computer. Nothing is uploaded anywhere. Every asset can be exported again at any size or color.

**Start here: open `index.html` in a browser.** It shows the logo, colors, type and all icons, and works offline.

| Folder | What is in it |
|---|---|
| `strategy/` | Who the brand is, voice, and what the owner still has to decide |
| `research/` | UI and UX research, and how Apple, Google and Meta build icon systems |
| `logo/` | The existing ring and dot mark, wordmark, lockups in five tones (SVG, PNG, Android) and usage rules |
| `app-icon/` | App icon for Android and the stores, favicons, social covers |
| `color/` | Tokens (JSON, CSS, Android, Compose), swatch sheet, contrast report |
| `icons/` | The 77 icon library in Tile, Line and Tint styles: SVG, sprite, PNG, Android vector, catalog data |
| `typography/` | Nunito font and licence, type roles |
| `mockups/` | Phone mockups of the chat screens in three color options, five app icon concepts, 20 vivid and 14 neutral icon background styles, and the black and silver direction (drawn, not the real app) |
| `tools/` | The scripts that build and export all of the above |

Older files `icon-512.png`, `mark-ink-1024.png` and `make_assets.py` are the current logo in ink on white. The new `logo/` files use the same shape, so they can replace them once the colors are approved.

## Export anything
See `tools/README.md`, `icons/README.md` and `logo/README.md`. One line gives you any icon or logo at any size and color, as PNG or SVG.

## State
- Designed and rendered on a Mac, viewed as images. Not yet in the app. Not tried on a phone.
- The old Ember colors were an earlier proposal. They are gone from the brand files and kept only in `mockups/explorations/`.
- Contrast is verified by the build for every color pair.
- No trademark search has been done for the name or the mark.
- Decisions the owner still has to make are listed at the end of `strategy/brand-strategy.md`.
